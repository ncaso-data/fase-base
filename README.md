# Fase Base: Fundamentos de Análisis de Datos

## Sobre este repositorio
Registro de mi fase base de aprendizaje en análisis de datos (octubre–noviembre 2026).
Aquí documento mi práctica en Python, SQL, Excel y Power BI aplicada a casos de negocio
reales, como el análisis de una cartera de préstamos.

## Contenido
- `leccion1.py`: variables, tipos de datos (`str`, `int`, `float`) e impresión de
  textos combinados con variables usando f-strings.
- `reto1.py`: cálculo del interés, el monto total y la cuota mensual de un préstamo.
- `leccion2.py`: definición de funciones para reutilizar un cálculo sin repetir la fórmula.
- `reto2.py`: función `calcular_cuota` y la diferencia entre `print` y `return`.

## Lo que aprendí
- Usar f-strings para mostrar resultados combinando texto y variables.
- Una función recibe datos (parámetros), hace un cálculo y lo **devuelve** con `return`.
- `print` muestra un valor en pantalla; `return` lo entrega para seguir usándolo.
  Sin `return`, la función devuelve `None`.

## Cómo ejecutarlo
Requiere Python 3. Desde la carpeta del proyecto:

    python reto1.py
